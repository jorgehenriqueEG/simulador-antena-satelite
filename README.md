# Simulador de Antena Satélite
## Descrição do Problema
Um script que calcula a potência de recepção de um sinal de satélite em uma antena parabólica, considerando a distância e o ganho da antena.
## Requisitos
* Calcular a perda de propagação no espaço livre.
* Somar o ganho da antena e o ruído do receptor.
* Determinar se o sinal é suficiente para decodificação.
## Exemplo de Uso
Entrada: Potência de transmissão 100W, distância 36000km, ganho 30dB.
Saída: Sinal insuficiente para decodificação.
